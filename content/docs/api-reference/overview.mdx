Qorax SEO Platform — публічний API для розробників, агентств та сторонніх сервісів, яким потрібен професійний SEO-функціонал без побудови власної інфраструктури.

## Автентифікація

Усі ендпоінти вимагають заголовок:

```
Authorization: Bearer qrx_ваш_ключ
```

Ключ створюється в **Dashboard → Налаштування → Developer API**. Сирий ключ показується лише один раз одразу після створення — збережіть його, відновити пізніше неможливо (можна лише створити новий).

## Базовий URL

```
https://qorax-api.mrcru96.workers.dev/api/v1
```

## Ліміти

Кожен ключ має ліміт **1000 запитів на місяць**, спільний на всі чотири ендпоінти нижче (виклик `/audit` і виклик `/schema` витрачають з одного й того самого лічильника). При вичерпанні ліміту запити повертають `429 Too Many Requests`.

## Доступні API

- **`POST /audit`** — технічний та SEO-аудит будь-якого URL (детально в статті «SEO Audit API»)
- **`POST /schema`** — генерація JSON-LD розмітки: Organization, Product, FAQ тощо (детально в статті «Schema API»)
- **`POST /report`** — готовий звіт (JSON або HTML) на основі аудиту (детально в статті «Reporting API»)
- **`POST`/`GET`/`DELETE` `/monitor`** — відстеження змін title/canonical/schema/robots/швидкості (детально в статті «Monitoring API»)

## Формат помилок

Усі помилки повертаються у форматі:

```json
{ "error": "Опис помилки українською" }
```

Типові статус-коди: `400` (невірний запит), `401` (відсутній або невірний ключ), `429` (ліміт вичерпано), `500` (внутрішня помилка сервера).

## CORS

Усі ендпоінти відкриті для будь-якого Origin (`Access-Control-Allow-Origin: *`) — це серверні виклики з вашого backend, не браузерний JavaScript з довільного сайту.
